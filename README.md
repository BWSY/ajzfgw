# 爱嘉租房 · 公司展示网站

爱嘉租房（AIJIA RENTAL）品牌官网，单页展示型静态网站。专注深圳租房市场，成立于 2023 年 7 月 17 日。

品牌主张：**有爱才有家**（Where there is love, there is home）。

## 预览

直接用浏览器打开 `index.html` 即可，无需构建、无需依赖。

## 技术说明

- 纯静态：单个 `index.html`，样式与脚本内联，无框架、无构建步骤。
- 响应式：桌面 / 平板 / 手机三档断点（1080px、900px、620px）。
- 图片：`images/` 目录本地存放，不依赖外链 CDN。
- 交互：滚动渐入（IntersectionObserver）、数字滚动、房源筛选、表单校验、锚点平滑滚动。
- 可访问性：`prefers-reduced-motion` 下关闭动画。
